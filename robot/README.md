# 로봇 소프트웨어

로봇에서 실행되는 자율주행·인식·통신 기능을 모은다. HMI 구현에는 의존하지 않고,
공유 통신 계약만 `../common/`에서 가져온다.

| 경로 | 역할 |
|---|---|
| `application/` | B2 실기·시뮬레이터, 인식, Nav2를 조립하는 ROS 2 bring-up과 로봇별 설정 |
| `slam_3d_to_2d/` | 3D LiDAR 지면분할과 2D SLAM 인식 패키지 |
| `bridge/` | HMI TCP 연결을 ROS 2 토픽·액션으로 변환하는 브릿지 |

점검 시나리오와 안전 게이트도 로봇의 운용 책임이므로 이 영역에 둔다. 이들은
`application/`의 bring-up에서 조립하되, HMI가 직접 제어 경로를 우회하지 않게 한다.

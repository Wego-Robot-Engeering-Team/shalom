# 브랜드 자산

발주기관 로고를 이 디렉터리에 넣는다.

| 파일 | 우선순위 | 비고 |
|---|---|---|
| `logo.svg` | 1 | 권장. 해상도 무관하게 선명하다 |
| `logo.png` | 2 | 최소 높이 128px, 배경 투명 |

넣은 뒤 `CMakeLists.txt` 의 `qt_add_resources(gcs_core "gcs_resources" ...)`
FILES 목록에 파일 경로를 추가하고 재빌드한다.

## ⚠️ 반드시 확인할 것

1. **공식 자산 파일을 발주기관에서 직접 수령한다.** 웹에서 내려받거나
   근사해서 그린 마크를 쓰지 않는다 — 비율·자간·색이 어긋나고,
   상표 사용 규정 위반이 된다.
2. **납품물에 대한 상표 사용 승인을 서면으로 받는다.** 브랜드 가이드가
   있으면 여백·최소 크기·배경색 제약을 함께 확인한다.
3. 자산이 없으면 UI 는 중립 마크(철도 도상 기호)로 폴백한다.
   특정 기업 상표를 모사하지 않으므로 승인 전까지 이 상태로 운용해도 문제없다.

착수 회의(1단계) 안건에 넣어 두는 것을 권한다.

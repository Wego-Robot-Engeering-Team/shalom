# 규격 변경 이력

버전은 봉투의 `v` 필드다. 기존 필드의 **의미가 바뀌면** 올린다. 채널 추가와
필드 추가는 올리지 않는다.

## SDK 0.1.0 / protocol v1

최초 규격. `docs/bridge_protocol.md` 의 내용을 외부 연동용으로 정리했다.

### 확정되지 않은 것

아래는 v1 에 들어 있으나 구현이 따라오지 않았거나 동작이 바뀔 수 있다. 여기에
의존하는 코드를 쓰기 전에 확인할 것.

**`sub` / `unsub`** — 브릿지가 수신 기록만 하고 구독 목록으로 쓰지 않는다.
연결된 클라이언트에 모든 상태 채널을 발행한다. 실제 필터링이 붙어도 보내던
쪽은 호환된다.

**`cmd/arm/ee_goal`** — `E_UNREACHABLE` 로 거절된다. 역기구학이 MoveIt2 의
몫인데 아직 연동되지 않았다.

**`state/nav.current_waypoint_id`** — 항상 `null`. 경유점 개념이 브릿지에 없다.

**`state/apriltag`** — 채널은 정의돼 있으나 검출기가 연동되지 않았다.

**`seq`** — 상태 채널 중 일부만 싣는다. 유실 감지에 쓰려면 채널별로 확인이
필요하다.

### 알려진 제약

**동시 접속 1.** 두 번째 연결은 즉시 닫힌다. 관측 전용 클라이언트를 따로 붙일
수 없다.

**팔 명령은 커미셔닝 전용.** `cmd/arm/preset`, `cmd/arm/joint_goal`은 고객
운영 API로 보장하지 않는다. 실제 팔 제어 경로와 권한이 납품 구성에서 승인되기
전에는 사용하면 안 된다.

**`cmd/cmd_vel` 의 상한 초과는 조용히 잘린다.** 거절되지 않으므로 클라이언트가
잘렸는지 알 수 없다. 로봇 로그에는 1초에 한 번 남는다.

**촬영 원본은 이 API 로 오지 않는다.** 로봇에서 NAS 로 직접 전송한다. 이 API 로
오는 것은 `capture/preview` 의 미리보기와 `state/capture_spool` 의 진행 상황
뿐이다.

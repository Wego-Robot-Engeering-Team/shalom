# Inspection HMI

로봇 또는 시뮬레이터의 브리지에 TCP로 연결하는 관제 프로그램이다.
통신 규약은 [bridge_protocol.md](../docs/bridge_protocol.md)를 참고한다.

## 빌드 및 실행

`shalom/hmi` 디렉터리에서 실행한다.

```bash
cmake --preset default
cmake --build --preset default --parallel 4
./build/inspection_hmi
```

처음 실행하면 설정에서 로봇 IP와 별칭을 등록한다. 연결 후에는 로봇이 보낸 ID를
주 표시로 사용한다. 실기와 시뮬레이터의 연결 방법은 같다.

## 주요 기능

- **목표 주행:** 지도에서 목적지를 지정한다. `정지`는 목적지를 유지하며, `재개`는 같은 목적지로 다시 주행한다. `취소`는 목적지를 지운다.
- **주행 속도:** `운용`에서 선속도(m/s)·각속도(rad/s)를 조절하고, `설정 > 주행`에서 최소·최대 범위를 설정한다. 로봇에 저장하며 수동·자율주행에 공통 적용한다.
- **Waypoints:** 현재 로봇 위치 또는 지도에서 좌표를 저장한다. 각 행에서 이름·X·Y·yaw를 편집하거나 `적용`으로 해당 위치까지 주행한다.
- **로봇팔:** 관절·끝단 입력을 3D로 미리 보고 전송한다. 끝단 입력은 역기구학으로 관절 목표를 계산한다. `미리보기 저장`은 화면의 자세를, `현재 자세 저장`은 최신 실제 관절값을 저장한다. `자세 관리`에서 미리보기·실행·편집·삭제한다. 전송에는 실행기와 팔 제어 권한이 필요하다.
- **미션:** `미션 현황`에서 상태 확인과 일시정지·재개·취소를 한다. `미션 관리`에서는 새 미션을 작성하거나 저장된 미션의 각 행에서 수정·실행·삭제한다. 팔 자세 단계는 저장할 수 있지만 아직 실행할 수 없다.
- **촬영:** 결과는 로봇이 NAS에 저장한다. HMI에서 결과를 보려면 로봇과 HMI 모두 NAS를 `/mnt/nas`에 마운트해야 한다.

## 테스트

```bash
/usr/bin/ctest --preset default --output-on-failure
```

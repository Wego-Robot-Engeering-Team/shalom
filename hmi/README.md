# Inspection HMI

로봇 브릿지에 TCP로 연결하는 관제 프로그램이다. 통신 규약은
[bridge_protocol.md](../docs/bridge_protocol.md)를 참고한다.

## 실행

모든 명령은 이 디렉터리(`shalom/hmi`)에서 실행한다.

```bash
cmake --preset default
cmake --build --preset default --parallel 4
./build/inspection_hmi
```

납품할 때도 같은 실행 파일을 설치 경로로 복사한다. 테스트 실행 파일과
유지보수 도구는 설치 대상이 아니다.

```bash
cmake --install build --prefix dist/inspection-hmi
```

처음 실행하면 HMI만 열리며 어떤 로봇에도 자동 연결하지 않는다. 설정에서
로봇 IPv4 주소와 선택 사항인 별칭을 등록한다. 연결 후에는 로봇이 전송한 ID가
주 표시이며, 별칭과 주소는 보조 정보로 표시된다. 이후 실행부터는 마지막으로 선택한 로봇의 상태
확인 포트가 응답할 때만 자동 연결하며, 상단 목록의 빨강·초록 점으로 등록된
각 로봇의 응답 상태를 확인할 수 있다.

실기와 시뮬레이터는 모두 브릿지가 있는 로봇으로 등록한다. HMI는 둘을
구별하지 않으며, 3D 팔은 받은 관절 상태와 입력 중인 목표를 표시하는 화면 기능이다.

실기 촬영은 버튼을 누르면 로봇이 곧바로 PNG와 JSON을 저장한다. 별도 저장 버튼은
없고, 로봇이 성공을 응답했을 때만 저장 완료로 표시한다. 로봇과 HMI에 같은 NAS를
`/mnt/nas`로 마운트해야 데이터 화면(`/mnt/nas/inspection`)에서 촬영물을 볼 수 있다.
마운트가 없으면 로봇은 촬영을 거절한다.

웨이포인트는 `위치 관리 > Waypoints`에서 로봇의 현재 위치로 추가하거나,
지도를 클릭해 위치를 찍고 드래그해 도착 방향을 정한 뒤 이름을
입력해 저장한다. 목록의 지점을 선택해 `편집`을 누르거나 두 번 클릭하면 이름,
X·Y, yaw를 수정할 수 있다. yaw는 화면에서 도(°)로 보이지만 로봇에는 라디안으로
저장된다.

미션 탭의 `미션 현황`은 로봇이 보고한 현재 미션 상태, 현재·다음 작업과
일시정지·재개·취소를 보여준다. 미션 선택과 실행은 아래 `미션 관리`에서 한다.
다음 미션을 자동 예약하는 큐는 아직 없다.
`미션 관리`에서 미션을 만들고 수정하거나 목록에서 삭제할 수 있다. 삭제한
미션은 로봇에 보관된다. 이동 단계는 저장된 웨이포인트를 이름으로 선택할 수
있다. 팔 자세 단계도 저장할 수 있지만 미션 실행기는 아직 연결되지 않아
그 단계가 포함된 미션은 실행 버튼이 비활성화된다.

## 테스트

```bash
/usr/bin/ctest --preset default --output-on-failure
```

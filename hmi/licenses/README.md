# 라이선스

납품 패키지에 포함되어야 하는 라이선스 전문을 이 디렉터리에 넣는다.

| 구성 요소 | 라이선스 | 파일 |
|---|---|---|
| Qt 6 | LGPL v3 | `LGPL-3.0.txt` |
| Qt 6 (LGPL 의 기반) | GPL v3 | `GPL-3.0.txt` |

## Qt LGPL 준수 요건

1. **동적 링크를 유지한다.** 정적 링크는 전체 소스 공개 의무를 발생시킨다.
   우리 코어를 정적으로 묶더라도 Qt 자체는 항상 동적 링크여야 한다.
2. **이용자가 Qt 를 교체해 재링크할 수 있어야 한다.** Qt DLL 을 실행 파일과
   분리해 배포하는 것으로 충족된다.
3. **사용한 Qt 의 정확한 버전을 밝힌다.** `VERSION.txt` 가 자동으로 기록한다.
4. **라이선스 전문을 함께 배포한다.** 이 디렉터리의 파일이 그 역할을 한다.

전문 파일은 이 디렉터리에 커밋해 둔다. 라이선스 전문은 그대로 복제·배포하도록
만들어진 문서이고, 저장소에 두어야 빌드가 준수 상태의 패키지를 스스로 만든다.
손으로 복사해 넣는 절차에 기대면 빠뜨린 채 납품된다 — 실제로 한동안
`README.md` 만 있었다.

LGPL v3 는 GPL v3 에 예외를 덧붙인 형식이라 **두 전문이 모두** 필요하다
(LGPLv3 §4(b)).
